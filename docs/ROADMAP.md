# MailFlow Studio Roadmap

## Near-term goals

- Improve onboarding for first-time users
- Add clearer startup and deployment diagnostics
- Expand automated test coverage for scheduler flows
- Strengthen admin visibility without exposing private data

## Planned improvements

- Better dashboard insights and a lightweight export option
- More guided email-composition workflows for teams and agencies
- Additional security review checks for scheduled sending and attachments
- Better deployment templates for Docker and cloud hosting

## Release philosophy

The project focuses on privacy, safety, and a predictable local-first workflow. Every new feature should improve reliability without exposing personal account data or SMTP credentials.
